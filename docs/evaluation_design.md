# 평가 설계

## 왜 평가가 어려웠나

처음에는 좋아요 수가 높은 댓글을 정답 데이터로 쓰면 된다고 생각했다. 그러나 좋아요 수는 댓글의 품질, 영상 조회수, 작성 시간, 노출 위치, 플랫폼 알고리즘이 섞인 결과였다.

또한 생성된 댓글이 좋은지 판단하려면 다음 질문에 답해야 한다.

- 영상의 시각적 내용과 맞는가?
- 오디오나 말소리, 분위기를 반영하는가?
- 음식 도메인 시청자가 공감할 만한가?
- 실제 한국 YouTube 댓글처럼 자연스러운가?
- 단순 설명문이 아니라 댓글다운 반응인가?

이 기준들은 자동화하기 어렵고, 단순 BLEU/ROUGE 같은 텍스트 유사도 지표와도 잘 맞지 않는다.

## 평가 축

프로젝트에서는 다음 세 축을 중심으로 평가 기준을 설계했다.

### 1. Contextual Grounding

댓글이 영상의 시각/청각 정보에 기반하고 있는지를 평가한다.

높은 점수를 받을 수 있는 예:

- 영상 속 재료, 조리 방식, 상황, 인물 행동을 구체적으로 언급
- 오디오, 말소리, ASMR, 분위기를 반영
- 해당 영상에만 적용되는 디테일을 포착

낮은 점수를 받을 수 있는 예:

- 어느 음식 영상에나 붙일 수 있는 범용 댓글
- 영상에 없는 내용을 꾸며냄
- 영상 내용과 모순됨

### 2. Semantic Resonance

댓글이 단순한 설명을 넘어 시청자의 감정이나 공감 포인트를 건드리는지 평가한다.

음식 도메인에서는 식욕, 대리만족, 가성비, 조리 과정의 쾌감, 익숙한 밈 등이 중요한 요소가 된다.

### 3. Human-like Tone

댓글이 실제 한국 YouTube 댓글처럼 자연스러운지 평가한다.

높은 점수를 받을 수 있는 예:

- 구어체, 감탄사, 적절한 밈 사용
- 지나치게 설명적이지 않은 짧고 자연스러운 반응
- 댓글창에서 실제로 볼 법한 리듬

낮은 점수를 받을 수 있는 예:

- 번역투
- 과도하게 공손한 설명문
- AI가 요약한 듯한 문장

## LLM-as-a-Judge

사람이 모든 댓글을 평가하기 어렵기 때문에, 멀티모달 LLM judge를 사용해 평가를 보조했다.

다만 LLM judge 역시 완벽한 정답자는 아니다. 따라서 이 프로젝트에서는 LLM judge를 절대적 평가자가 아니라 다음 용도로 사용했다.

- 영상과 댓글의 관련성 필터링
- 생성 결과 간 상대 비교
- 평가 기준을 명시적으로 고정하는 도구

발표자료의 실제 평가 예시는 다음과 같다.

```json
{
  "generated_comment": "술취해서 골골거리는데 엄마랑 용케도 깨어났네 ㅋㅋㅋ",
  "scores": {
    "contextual_grounding": 85,
    "semantic_resonance": 70,
    "human_like_tone": 80,
    "average_score": 78
  }
}
```

이 예시는 댓글이 영상의 상황을 어느 정도 반영하고, 한국어 댓글 문체도 자연스럽지만, 음식 도메인 시청자의 감정이나 공감 포인트를 더 구체적으로 건드리지 못하면 semantic resonance가 제한될 수 있음을 보여준다.

## 배운 점

이 프로젝트에서 가장 크게 배운 점 중 하나는, 생성 모델 프로젝트에서 evaluation은 마지막 단계가 아니라는 것이다.

문제 정의 단계에서 "무엇을 좋은 출력으로 볼 것인가"를 정하지 못하면, 이후의 데이터 수집, 학습, 모델 비교가 모두 흔들린다.

특히 NLP와 생성 과제에서는 정답이 하나로 고정되지 않는 경우가 많다. 이때 중요한 것은 완벽한 평가 지표를 찾는 것이 아니라, 현재 문제에서 어떤 proxy를 쓰고 있으며, 그 proxy가 어떤 편향과 한계를 갖는지 명확히 설명하는 일이다.
