# 데이터 윤리와 공개 범위

이 프로젝트는 YouTube Shorts 영상과 댓글 데이터를 다루었다. 따라서 공개 저장소에는 원본 데이터와 민감한 정보를 포함하지 않는다.

## 공개하지 않는 데이터

다음 자료는 저장소에 포함하지 않는다.

- 원본 YouTube 영상 파일
- 원본 댓글 전체 데이터
- 댓글 작성자명, 채널명 등 개인 식별 가능성이 있는 정보
- API key, access token, Hugging Face token
- 다운로드된 ChromeDriver, binary executable
- Colab 개인 경로가 남은 원본 notebook

## 공개 가능한 자료

대신 다음 자료만 포함한다.

- 익명화된 toy sample
- 데이터 스키마
- 전처리와 보정 로직
- 평가 prompt 구조
- 실험 설계와 한계 설명

## 데이터 사용 원칙

이 프로젝트의 데이터 사용 원칙은 다음과 같다.

1. 교육 및 연구 목적에 한정
2. 원본 영상/댓글 재배포 금지
3. 댓글 작성자 식별 정보 제거
4. API key 공개 금지
5. 플랫폼에 과도한 요청을 보내지 않도록 delay와 수집 범위 제한
6. 공개 저장소에는 재현 가능한 구조와 샘플만 제공

## 왜 샘플만 공개하는가

댓글 데이터는 공개 댓글이라 하더라도 작성자의 표현과 맥락을 포함한다. 또한 영상 파일은 원저작자의 콘텐츠이므로 저장소에 포함하거나 재배포하지 않는 것이 맞다.

따라서 이 저장소는 원본 데이터를 제공하기보다, 어떤 형태의 데이터를 수집했고 어떤 방식으로 정제했는지 설명하는 데 초점을 둔다.
